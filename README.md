# Flip 7 — compteur de points

PWA installable pour pointer les manches de **Flip 7** en touchant les vraies cartes.

- ouvre l'URL dans Chrome (Android) ou Safari (iOS)
- menu ☰ → « Installer sur l'écran d'accueil »
- fonctionne hors ligne une fois installée

Mono-fichier (`index.html`), aucune dépendance, données en `localStorage`.
